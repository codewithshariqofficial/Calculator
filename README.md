# Simple Calculator

A clean, simple calculator built with HTML, CSS, and JavaScript. No frameworks, no dependencies — just open `index.html` in your browser.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Percentage (%) and square root (√)
- Clear (C), Clear Entry (CE), and backspace (⌫)
- Keyboard support (digits, operators, Enter, Backspace, Esc)
- Safe expression evaluation (no `eval`)

## How to use

1. Open `index.html` in any modern browser.
2. Click the buttons or use your keyboard to enter an expression.
3. Press `=` or `Enter` to calculate.

## Files

- `index.html` — structure
- `style.css` — styling
- `script.js` — calculator logic
